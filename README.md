# Thomas Wimart — Portfolio

Personal portfolio site: [thomaswimart.fr](https://thomaswimart.fr)

## Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Framer Motion

## Commands

```bash
npm install
npm run dev       # local dev server
npm run build     # production build → dist/
npm run lint      # ESLint
npm run preview   # preview production build
```

## Content

Edit site content in:

- `src/data.js` — projects, experience, skills, personal info
- `src/translations.js` — FR/EN copy
